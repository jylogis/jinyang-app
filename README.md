# 진양로지스틱스 기사앱

기사용·관리자용 모바일 웹앱 (휴대폰에서 링크를 열고 "홈 화면에 추가"하면 앱처럼 사용).

## 현재 단계: 기본 앱 (1차)
- 로그인 / 기사 회원가입(기본 정보 + 서류 사진 4종)
- 기사: 홈, 공지사항, 급여내역(넘버 임대 기사는 임대료 안내), 팀즈 감지, 내 정보(감차 요청)
- 관리자: 업체 선택 → 업체별 홈·공지·급여·팀즈·설정(기사 정보 관리, 감차 승인, 넘버 임대료 보내기)
- 데이터는 아직 휴대폰(브라우저)에만 저장됨 — 예시 데이터 포함

## 다음 단계
- Supabase 연결 (기사 정보·서류 사진·공지·급여 저장, 기사는 본인 정보만 / 관리자는 업체 전체)
- 실제 로그인(전화번호 + 비밀번호)

## 파일
- `index.html` — 앱 전체 (Vue 3)
- `manifest.json`, `icon.svg`, `sw.js` — 홈 화면 추가용
