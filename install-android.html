크롬으로 여는 중이에요…

설치는 크롬에서만 할 수 있어요. 크롬이 자동으로 열리지 않으면 아래 버튼을 눌러 주세요.

크롬으로 열기

크롬이 없다면 Play 스토어에서 "Chrome"을 설치한 뒤 다시 열어 주세요.

아이폰이시군요

아이폰은 전용 설치 화면에서 진행해 주세요.

아이폰 설치 화면으로

휴대폰에서 열어 주세요

이 링크를 카카오톡으로 받아 휴대폰에서 눌러 주세요.

  1. 1앱 설치하기

    설치하면 휴대폰 홈 화면에 JY 아이콘이 생겨요.

    설치 버튼이 안 보이면 이렇게 해 주세요.

    1. 크롬 오른쪽 위 ⋮ (점 3개)를 눌러요
    2. "앱 설치" 또는 "홈 화면에 추가"를 눌러요
    3. "설치"를 눌러요
  2. 2알림 허용하기 필수

    배차·공지·감차 승인 소식을 알림으로 받아요. 꼭 "허용"을 눌러 주세요.

    알림이 차단되어 있어요. 이렇게 다시 켜 주세요.

    1. 주소창 왼쪽 설정(자물쇠) 아이콘을 눌러요
    2. "권한" 또는 "사이트 설정" → "알림"
    3. "허용"으로 바꾼 뒤 아래 버튼을 눌러요
  3. 3시작하기

    홈 화면의 JY 아이콘을 눌러 앱을 열고 로그인해 주세요.

    지금 바로 열기
