아이폰에서 열어 주세요

이 링크를 카카오톡으로 받아 아이폰에서 눌러 주세요.

아래 순서대로 하면 홈 화면에 JY 아이콘이 생겨요. 설치 후 앱을 처음 열면 알림 허용을 물어봐요. 꼭 "허용"을 눌러 주세요.

  1. 1공유 버튼 누르기

    화면 아래 가운데(또는 주소창 옆)의 공유 버튼을 눌러요.

    공유
  2. 2"홈 화면에 추가" 누르기

    목록을 아래로 내려 "홈 화면에 추가"를 눌러요.

    홈 화면에 추가
  3. 3오른쪽 위 "추가" 누르기

    이름이 "진양"인지 확인하고 "추가"를 눌러요.

    진양추가
  4. 4JY 아이콘으로 열고 알림 허용

    홈 화면의 JY 아이콘을 눌러 열면 알림 허용 창이 떠요. "허용"을 눌러 주세요.

    아이폰은 iOS 16.4 이상에서, 홈 화면에 설치한 앱으로만 알림을 받을 수 있어요.
